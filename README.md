# cjhuaxin's Homebrew Tap

Homebrew tap for apps by [cjhuaxin](https://github.com/cjhuaxin).

## Usage

```bash
brew tap cjhuaxin/tap
```

## Casks

### 小小万年历 / Tiny Chinese Lunar Calendar

Lightweight Chinese lunar calendar for the macOS menu bar — lunar dates,
solar terms, PRC public-holiday markers and live weather.

```bash
brew install --cask xiaoxiao-wannianli
```
